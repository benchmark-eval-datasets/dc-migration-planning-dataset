# Data Center Migration Planning Dataset

A curated collection of infrastructure planning documents for a multi-facility data center consolidation and migration project. Covers server inventory, vendor evaluation, financial modelling, network architecture, workload analysis, compliance auditing, and operational telemetry.

## Contents

| File | Format | Description |
|------|--------|-------------|
| `server_inventory_export.xlsx` | XLSX | Physical and virtual server inventory with storage arrays, network equipment, and change history |
| `workload_requirements.xlsx` | XLSX | Workload catalog with dependency matrices, SLA targets, and performance baselines |
| `vendor_pricing_comparison.xlsx` | XLSX | Colocation, cloud IaaS, and managed services pricing with TCO model and historical quotes |
| `capacity_planning_model.xlsx` | XLSX | DCN topology assessment, bandwidth demand forecast, power/cooling capacity, and 3-year growth projection |
| `cloud_tco_stochastic_model.xlsx` | XLSX | Monte Carlo TCO simulation with CapEx/OpEx assumptions, risk discounting, carbon emissions, and sensitivity analysis |
| `bandwidth_utilization_logs.csv` | CSV | Per-interface bandwidth utilization with QoS classification across facilities |
| `environmental_sensor_data.csv` | CSV | Temperature, humidity, and airflow sensor readings across data center zones |
| `storage_performance_analysis.csv` | CSV | IOPS, throughput, and latency metrics per storage array and volume |
| `rack_layout_mapping.csv` | CSV | Physical rack assignments with power draw, weight, and operational status per server |
| `vendor_a_proposal.pdf` | PDF | Colocation and managed services proposal from Vendor A (TerraVault) |
| `vendor_b_sla_terms.pdf` | PDF | Service level agreement terms from Vendor B (NovaBridge) |
| `current_dc_contract_summary.pdf` | PDF | Existing data center lease and service contract summary |
| `migration_algorithm_specifications.pdf` | PDF | Technical specification for migration sequencing and dependency resolution |
| `performance_test_results.pdf` | PDF | Pre-migration performance baseline testing results |
| `power_cooling_audit.pdf` | PDF | Independent power and cooling efficiency audit report |
| `vm_consolidation_assessment.pdf` | PDF | Virtual machine consolidation feasibility analysis |
| `vendor_evaluation_summary.pdf` | PDF | Multi-criteria vendor evaluation scorecard |
| `project_charter.docx` | DOCX | Project charter with scope, budget, RACI matrix, risk register, timeline, facility compliance assessment, and disaster recovery runbook |
| `network_topology_architecture.docx` | DOCX | Network architecture documentation with VLAN assignments, circuit details, and embedded topology, security zone, and bandwidth allocation diagrams |
